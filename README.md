# FF14 製作規劃工具（繁中服）

純靜態網站（無需後端、無需建置），可直接部署在 GitHub Pages。

## 功能

| 頁面 | 說明 |
| --- | --- |
| 搜尋物品 | 以繁中名稱搜尋所有可製作物品（一般配方＋部隊工房，含潛水艇組件），可依職業、等級、分類篩選 |
| 快速套裝 | 同等級、同系列名稱的可製作裝備整理成一組（例：Lv100 金拇指工具、雀翎巧匠），可依製作／採集／戰鬥與職業篩選，勾選部位後一次加入清單 |
| 製作清單 | 多份清單、數量、同一物品多職業配方可切換；支援匯出／匯入／分享連結 |
| 素材準備 | 條列式分成「成品／半成品／基礎素材」，半成品與基礎素材再依物品種類（石材、金屬、木材…）分組。勾選已完成的成品或半成品時，底下用到的素材會自動扣除；可填持有數量、把半成品改為購買、複製或列印 |
| 巨集計算 | 版面參考 BestCraft：上方耐久／CP／進度／品質，左側技能圖示，右側流程與「求解器／巨集／匯入／步驟明細／配方與 HQ 素材」分頁 |
| 職業數值 | 8 個製作職業各自的等級、製作力、加工精度、CP、專家設定，存在瀏覽器 localStorage，巨集計算自動帶入 |

## 資料

- 物品、配方、公司工房、潛水艇零件：[thewakingsands/ffxiv-datamining-tc](https://github.com/thewakingsands/ffxiv-datamining-tc)（繁中服）
- 圖示：直接引用 [XIVAPI v2](https://v2.xivapi.com)
- 重新產生資料：

```bash
python3 -I scripts/build_data.py --fetch --raw ./raw --out data
```

`.github/workflows/update-data.yml` 會每週二自動執行一次（台灣時間 10:00，也可在 Actions 手動觸發）。若來源資料尚未更新，重建結果不會變。

## 本機執行

```bash
python3 -m http.server 8000   # 然後開 http://localhost:8000
node tests/planner_test.js     # 素材計算測試
node tests/solve_test.js 740 5500 5400 720 1500   # 求解器測試：配方等級表 ID、製作力、加工精度、CP、光束寬度
```

## 巨集計算的做法與限制

- `js/sim.js` 是自行實作的製作模擬器：進度／品質公式、內靜、崇敬、改革、闊步、儉約、掌握、最終確認、堅信、專心致志、連續加工 combo 等。
- 求解流程：光束搜尋（beam search，附「一定能收尾」的可行性檢查）→ 模擬退火優化，所有結果都會再用模擬器重新驗證。這是**啟發式搜尋**，不保證是理論最佳解，不同次執行可能略有差異；「精細」模式會多跑幾輪。
- 只模擬「通常」狀態；高速製作、倉促等隨機成功率技能，以及高難度（Expert）配方的狀態變化不在求解範圍內。
- 以下規則依記憶與社群資料實作，**尚未在遊戲內逐項核對**，使用前請先用「手動編輯／模擬」與遊戲內實際數值比對：
  - 閒靜給予 2 層內靜、坯料加工／集中加工給予 2 層
  - 最終確認、專心致志不消耗增益回合；任何技能都會中斷 combo（保守作法）
  - 巧奪天工每次製作限用一次
  - 進度與品質增量的取整順序（可能與遊戲相差 1 左右）
  - 初始品質（HQ 素材）的估算公式
- 巨集等待時間：增益類 2 秒、其餘 3 秒；每個巨集最多 15 行（含最後一行 `/echo` 提示）。
